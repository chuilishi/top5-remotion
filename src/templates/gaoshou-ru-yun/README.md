# 高手如云 (GaoShouRuYun) 模板

抖音/B站经典梗视频模板——"现在的 xxx" vs "以前的 xxx" 对比，配合 BGM 卡点产生反差效果。

## 视频规格

| 属性 | 值 |
|------|-----|
| 分辨率 | 1080×1920 (竖屏) |
| 帧率 | 30fps |
| 总帧数 | 1797 (≈59.9s) |

## 结构时间线

视频分为**前段**和**后段**两部分，通过亮度过渡衔接：

| 帧 | 时间 | 事件 |
|----|------|------|
| 0–889 | 0:00–0:29.6 | **前段**：正常播放视频，顶部显示`前段文字`（如"现在的最终boss:"） |
| 890 | 0:29.667 | 画面亮度开始逐渐降低（dim overlay 渐入） |
| 897 | 0:29.900 | **切换点**：文字瞬间切换为`后段文字`（如"以前的最终boss:"），画面全黑→开始恢复 |
| 903 | 0:30.100 | 画面恢复正常亮度 |
| 927 | 0:30.900 | **主卡点**：图形学效果触发（色差 Chromatic Aberration），也是 BGM 最关键的音乐卡点 |
| 980, 1035, 1091 | 0:32.7, 0:34.5, 0:36.4 | 后续节拍卡点（等间距，跟随音乐节奏） |

## Props (schema)

```typescript
{
  前段文字: string    // 前半段显示的文字，如"现在的最终boss:"
  后段文字: string    // 后半段显示的文字，如"以前的最终boss:"
  视频路径: string    // 视频素材路径（相对于 public/），为空时显示渐变背景
  音乐卡点秒: number  // BGM 中主卡点对应的秒数，用于对齐音频（默认 40.6）
}
```

## 音频对齐机制

BGM 文件为 `public/高手如云的小曲.mp3`。模板通过 `音乐卡点秒` 参数计算 `trimBefore`，使 BGM 中的节拍点精确落在第 927 帧（视频主卡点）。

公式：`trimBefore = (音乐卡点秒 - 927/30) × fps`

## 视觉效果

- **Dim Overlay**：帧 890–903 之间通过黑色遮罩 opacity 实现亮度渐暗→渐亮过渡
- **Chromatic Aberration**：色差分离效果（SVG filter），用于卡点瞬间的视觉冲击（组件 `ChromaticAberration.tsx`）
