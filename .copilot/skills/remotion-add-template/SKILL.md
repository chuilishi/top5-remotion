# Add Remotion Template

## Architecture

Each template lives in `src/templates/<name>/` and is registered in `Root.tsx` as a `<Composition>`.

Template ID in `index.ts` must match the `template:` field in any `project.yaml` that uses it.

`defaultProps` must be a **named export** so Remotion Studio can trace and save it.

## Checklist

### 1. Create template files

```
src/templates/<name>/
  index.ts          ← exports templateDef + defaultProps
  <Name>.tsx        ← React component
  schema.ts         ← zod schema (enables Studio sidebar controls)
  config/           ← optional, for generated config files
```

**index.ts pattern:**
```ts
import { MyComp } from "./<Name>";
import { mySchema } from "./schema";
import type { TemplateDefinition } from "../registry";

export const myDefaultProps = { /* match schema */ };

export const myTemplate: TemplateDefinition = {
  id: "<Name>",
  component: MyComp,
  schema: mySchema,
  width: 1920,
  height: 1080,
  fps: 30,
  durationInFrames: 300,
  defaultProps: myDefaultProps,
  // optional: calculateMetadata for dynamic duration
};
```

### 2. Register in `src/templates/index.ts`

Add re-exports and templateMap entry:
```ts
export { myTemplate, myDefaultProps } from "./<name>";
// + add to templateMap
```

### 3. Register in `src/Root.tsx`

Add a `<Composition>` block with **direct named import** for defaultProps:
```tsx
import { myTemplate, myDefaultProps } from "./templates";
const m = myTemplate;
<Composition
  id={m.id}
  component={m.component}
  schema={m.schema}
  durationInFrames={m.durationInFrames}
  fps={m.fps}
  width={m.width}
  height={m.height}
  defaultProps={myDefaultProps}
/>
```

### 4. Create a project that uses this template

```
projects/<project-name>/
  project.yaml      ← must contain `template: <Name>`
```

### 5. Create public assets directory (if needed)

```
public/<project-name>/   ← videos, audio, images referenced via staticFile()
```

### 6. Update render.ps1 and package.json

Both currently **hardcode** `Top5Video`. If the new template needs rendering:
- `render.ps1` line: `npx remotion render Top5Video` → use dynamic ID
- `package.json` build scripts: same hardcoded `Top5Video`

### 7. Build config support

`scripts/build-config.mjs` has a branch for `template !== "Top5Video"` that generates placeholder configs. If the new template needs YAML → TS config generation, add a branch there.

## Critical rules

- `defaultProps` on `<Composition>` must be a directly imported variable, NOT a property access like `t.defaultProps`
- Template ID must be consistent across: `index.ts` → `templateMap` → `project.yaml`
- `src/templates/active.ts` is auto-generated by `build-config.mjs` — never edit manually
- Run `npm run project -- <project-name>` to switch, then `npm run config` to generate
